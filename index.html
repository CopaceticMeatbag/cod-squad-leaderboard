Setup Required

This leaderboard syncs through JSONBin.io (free). To finish setup:

  1. Create a free account at jsonbin.io.
  2. Create a new bin with the starter content: {"squadName":"MY SQUAD","players":[],"matches":[]}
  3. Copy the Bin ID from the URL of your new bin.
  4. Go to API Keys in JSONBin settings and create an Access Key with both readBin and updateBin enabled.
  5. Open the index.html file in your GitHub repo and paste your Bin ID and Access Key into the CONFIG block near the top.
  6. Commit and push. GitHub Pages will rebuild within ~30s.
